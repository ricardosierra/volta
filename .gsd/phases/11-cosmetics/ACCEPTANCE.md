| A11-03 | Inventário persiste; item é permanente | teste |

| A11-05 | Preview ao vivo antes de equipar | manual |
| A11-06 | Estados da grade claros (possuído/equipado/bloqueado/comprável) | manual |
| A11-07 | Saldo insuficiente sem dark pattern | revisão contra `monetization.md` |
| A11-08 | Todo cosmético legível nos 8 temas | matriz de auditoria |
| A11-09 | Teste cego de ameaça ≥ 90 % com skins variadas | 5 pessoas |
| A11-10 | Troca aplicada em < 200 ms | medição |
| A11-11 | Adicionar item novo não exige código | inspeção |
