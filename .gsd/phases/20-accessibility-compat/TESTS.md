# GSD 20 — Testes

## Dispositivos
Checklist de `docs/mobile/device-matrix.md` em 4 Android + 3 iPhone + 1 iPad, com registro por
aparelho. Complemento em nuvem de dispositivos cobrindo ≥ 20 modelos.

## Capturas automatizadas
Todas as telas × 6 formatos × 2 escalas × temas de acessibilidade.

## Auditoria de acessibilidade
```text
[ ] contraste (script)
[ ] cor + forma em toda identificação
[ ] redundância de canal para toda informação crítica
[ ] alvos >= 48 dp
[ ] nenhum gesto complexo obrigatório
[ ] tutorial sem tempo limite
[ ] partida completa com todas as reduções
```

## Playtest
Sessão com pelo menos uma pessoa com daltonismo, se possível; caso contrário, simulador +
checklist. Registrar limitação com honestidade.

## Beta
Build de teste fechado, ≥ 30 aparelhos, crash-free ≥ 99 % por 7 dias.
