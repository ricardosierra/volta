# GSD 20 — Requisitos

| # | Requisito | Verificação |
|---|---|---|
| R20-01 | Safe area correta em toda a matriz de proporções e aparelhos | capturas + dispositivo |
| R20-02 | Tablet com layout adaptado (não esticado) | dispositivo |
| R20-03 | Low-end a 60 FPS com preset Low | dispositivo |
| R20-04 | 90/120 Hz e LTPO sem alterar comportamento | dispositivo |
| R20-05 | 3 temas de daltonismo, fora da loja, em `Accessibility` | manual |
| R20-06 | Modo de alto contraste | manual |
| R20-07 | Escala de UI 0,9–1,25 sem sobreposição em nenhuma tela | capturas |
| R20-08 | `Reduce shake`, `Reduce flashes`, `Reduzir sons intensos`, `Haptics off` | teste |
| R20-09 | Jogo completo e divertido com todas as reduções ativas | playtest |
| R20-10 | Nenhuma informação existe só na cor | auditoria |
| R20-11 | Nenhuma informação existe só no som | auditoria |
| R20-12 | Nenhuma ação exige toque duplo, longo ou multitoque | auditoria |
| R20-13 | Alvos ≥ 48 dp em toda a UI | script |
| R20-14 | Decisão sobre upgrade da engine, com custo medido | ADR ou registro no backlog |
