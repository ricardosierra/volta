# GSD 25 — Post Launch

**Status:** ⬜ pendente · **Depende de:** GSD 24 · **Tarefas:** 7 · **Prefixo:** `POST`
**Branch:** `develop` (ciclo contínuo, com releases `v0.2.0`, `v0.3.0`, …)

## Objetivo

> Transformar o jogo publicado em produto vivo: balanceamento por dados reais, conteúdo novo,
> monetização, eventos e operação contínua.

Esta fase não "termina" — ela vira o ritmo de trabalho do projeto. Cada ciclo é uma minor
(`v0.2.0`, `v0.3.0`…), com seu próprio conjunto de tarefas derivado dos dados.

## Escopo

**Entra:** balanceamento com dados de produção · monetização (anúncios rewarded, IAP, remove
ads) · season pass cosmético · temporadas e eventos · arenas e modos novos · multiplayer (se a
GSD 17 recomendar) · operação e suporte.

**Regra que continua valendo:** nada aqui pode ferir os pilares. Monetização nunca ganha de
diversão, responsividade, clareza, game feel, performance ou qualidade visual.
