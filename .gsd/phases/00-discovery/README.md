# GSD 00 — Discovery & Product Definition

**Status:** ✅ concluída — 2026-08-24
**Marco:** fundação do plano
**Branch:** — (executada no commit inicial do repositório)

## Objetivo

Transformar uma ideia ("um jogo de conquista territorial mobile") em um projeto executável:
visão, público, diferencial, pilares, regras formais, controles, direção visual, stack,
arquitetura e um plano de 26 fases onde nenhuma decisão fundamental fica em aberto.

## Escopo

**Entra:**
- Visão de produto, público-alvo, diferencial e métrica-norte
- Cinco pilares de design com critério de decisão
- Regras formais do jogo, com estados e 12 casos de borda normativos
- Modelo de controle, modos, bots, score, progressão, economia, monetização
- Direção de arte, temas, VFX, áudio, game feel
- Arquitetura do cliente, sistema de território, FSMs, save, rede, config, log, debug
- 14 ADRs
- Estratégia de testes, orçamento de performance, benchmarks, processo de release
- Master Repository completo com o sistema GSD e 26 fases planejadas

**NÃO entra:**
- Qualquer linha de código de gameplay
- Projeto Godot (é GSD 01)
- Arte, áudio ou protótipo

## Resultado

`MASTER PLAN READY`. O projeto pode ser executado por comando, fase a fase.
