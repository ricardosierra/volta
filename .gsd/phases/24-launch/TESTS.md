# GSD 24 — Testes

## Pré-submissão
Toda a suíte, a partir da **tag**, não do branch. Builds finais instaladas e jogadas por 30 min
em pelo menos 2 aparelhos por plataforma.

## Pós-rollout (por degrau)
```text
[ ] crash-free >= 99,5 %
[ ] ANR dentro do limite do Play
[ ] retenção D1 dentro do esperado
[ ] funil de onboarding sem queda anômala
[ ] erros da API estáveis
[ ] avaliações sem padrão de reclamação grave
```

## Rollback
Procedimento pronto para executar em minutos, já ensaiado na GSD 23.
