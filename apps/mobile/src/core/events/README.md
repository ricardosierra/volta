# events/

Payloads tipados para eventos complexos entram aqui conforme necessário (ex.:
`MatchStartedEvent` em GSD 06). Os eventos desta fase (`config_loaded`, `save_loaded`,
etc., em `../event_bus.gd`) usam apenas tipos primitivos e não precisam de payload
dedicado ainda.

**Preenchido em:** conforme a necessidade, a partir de GSD 06.
