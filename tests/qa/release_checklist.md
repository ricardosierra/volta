# QA Release Checklist

## 1. Gameplay
- [ ] Match starts cleanly without stutter.
- [ ] Territory captures compute correctly on large scales.
- [ ] Bots exhibit expected behaviors.
- [ ] Game Over screen fires accurately.

## 2. Progression
- [ ] XP accumulates and levels up correctly.
- [ ] Currency is awarded per match rules.
- [ ] Skins can be purchased and equipped.

## 3. Tech
- [ ] Safe areas respected on all edges.
- [ ] Pausing the app suspends the game loop.
